# Conecta Móveis

Plataforma brasileira de descoberta, divulgação e conexão entre pessoas e profissionais do setor moveleiro (montadores, marceneiros, lojas de planejados, marcenarias e projetistas).

## Diretrizes de Negócio
No MVP, o Conecta Móveis:
- **NÃO** recebe pagamento de serviços
- **NÃO** define preços ou orçamentos
- **NÃO** agenda execução de serviços
- **NÃO** garante qualidade, prazo ou resultado
- **NÃO** atua como prestadora ou intermediadora jurídica

A negociação, contratação e pagamento ocorrem diretamente entre as partes.

## Requisitos do Ambiente
- Node.js >= 20
- npm >= 10

## Instalação e Execução
```bash
# Instalar dependências
npm install

# Rodar servidor de desenvolvimento
npm run dev

# Checagem de tipos
npm run typecheck

# Linting
npm run lint

# Testes unitários
npm run test

# Testes E2E (Playwright)
npm run test:e2e

# Build de produção
npm run build
```
